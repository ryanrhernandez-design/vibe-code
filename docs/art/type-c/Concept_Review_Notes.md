# Concept review and limitations

Reviewed for: complete roster coverage, recognizable faction families, complete figures, readable titles, and presence of front/side/rear concept views. All 20 requested expansion images are present and decode successfully.

- Turnarounds: several side panels are three-quarter rather than strict orthographic profiles. Accessories and trim may shift. Treat sheets as concept references; a modeler must resolve the final geometry.
- Boards: painted grid seams and bench sockets are not dependable exact counts. Use board_topology.svg and board_topology.json for the mandatory 7x8 grid, horizontal split and eight-slot benches. Do not trace the images as geometry.
- Upgrade sheet: highlights and trim differences are intentionally subtle at two stars. Explicit star badges must remain the primary cue.
- UI material study: player placement, example values, character cards and button labels are illustrative. It omits some required controls and is not the comprehensive UI specification. Use the subsequent comprehensive UI proposal for layout decisions.
- Nautical emblem: renders sometimes use trident/compass decorations. Canonical UI faction mark is shell.
- Specular glare, ornament size and silhouette readability still need validation in the actual game camera. No device performance, rig, animation or accessibility validation is claimed.
